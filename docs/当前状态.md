# YMGUI 当前状态

> 更新日期：2026-08-29
> 本文是 V1/V2 DEVLOG 的去时间线汇总：列出已完成的能力、当前规模、验证基线和已知边界。与历史记录冲突时，以代码、测试、CMake 和本文为准。

## 项目定位与规模

YMGUI 是面向嵌入式和裸机的跨平台 GUI 库，使用 C99 + GNU 扩展。核心路线是软件光栅化、保留模式对象树、脏矩形和 band 分块刷新。桌面端通过 SDL 充当假 LCD，真机通过 `flush_cb` 接入 LCD/framebuffer；控件和渲染核心不依赖 SDL、GPU 或 OS 消息泵。

- `YMGUI/` 库本体共 10 个层、49 个 `.c` 文件。
- 27 个具名控件，加 base 对象/容器共 28 类 UI 对象。
- 5 类核心图元：填充、文字、直线、图片和圆/弧。
- 根工程 35 个 CTest，`Demo/` 下 28 个 `demo_*.c`，`project_Demo/` 下 10 个完整应用。
- framebuffer 支持 1bpp、8 位灰度、RGB565 和 RGB888，CMake 默认 RGB565。

## 目录与分层

```text
YMGUI/
  CONFIG/   公共类型、颜色/定点宏、裁减开关、内存适配
  DEBUG/    assert 和日志
  COMMON/   几何与 Q15 三角查表
  OPOBJ/    对象树、生命周期和 top layer
  CORE/     软件光栅化、字体和图像图元
  GUI/      失效区、分块刷新、事件、焦点和布局
  HAL/      显示、输入、时钟和剪贴板接口
  WIDGET/   控件
  STATE/    状态容器、观察者和控件绑定
  PLUGIN/   静态插件注册表和可选 OS 动态加载器
```

`YMGUI/` 是可移植库本体。`SDL_LCD/` 是 Linux/Windows/Android 假 LCD 和输入桥接；`Demo/` 是单控件/机制演示；`project_Demo/` 是独立完整应用；`tests/` 是行为规格和回归测试。

`tools/` 放置字体生成器、GB2312 外部字模 blob 和仓库级检查/测试脚本，不随 `YMGUI/` 移植到 MCU。

## 已完成的基础能力

### 显示与渲染

- `GYdisp.flush_cb` 是唯一必须的显示硬件接口，接收区域和连续像素块。
- draw buffer 可小于整屏，脏区会被切成 band 逐块渲染和 flush。
- 支持多脏矩形；超过 `GY_INV_MAX` 后退化为合并包围盒，无脏区时 `YMGUI_Refresh()` 空转返回。
- 支持单缓冲同步 flush，也支持 `buf1/buf2` 乒乓和 DMA 异步重叠；中断通过 `YMGUI_Disp_FlushReady()` 通知完成。
- `frame_done_cb` 在一帧的所有脏区/band 完成后通知桌面后端 Present，真实 LCD 可不注册。
- `YMGUI_COLOR_DEPTH=1/8/16/24` 对应单色、灰度、RGB565 和字节顺序 R/G/B 的 RGB888。`GYpx` 是公开 ABI，库与应用必须同深度构建。

### 对象、裁剪与布局

- 保留模式父子/兄弟树，支持递归级联释放、显隐、状态位、自定义绘制和事件回调。
- 命中测试和绘制共用叠放顺序；子节点可裁剪到父视口。
- `top_layer` 是独立全屏层，用于 Dropdown、MsgBox、FileDialog 和应用自定义浮层。
- 通用滚动捕获、子裁剪、绝对坐标和对象失效已落地。
- 可裁减的一次性 `Stack`/`Align` 布局助手只计算并写坐标，不增加每对象运行时 RAM。

### 输入、事件与焦点

- 指针事件包括按下、按住、抬起、移出抬起、点击和双击，具有 pressed-object 捕获语义。
- 键盘支持可打印字符、方向、Backspace、Delete、Enter、Home/End、Tab 和 Ctrl/Shift 组合。
- `YMGUI_FocusNext()` 按对象树前序轮转焦点，跳过 Hidden 子树并末尾回卷。编辑控件先消费 Tab，未消费时才轮转焦点。
- 滚轮保留横纵有符号增量，派发给指针位置命中的对象。
- 右键短点是一次性 `ContextRequested`；右键拖动和触摸长按后拖动具有 Requested/Dragging/Released/Cancelled 独立捕获链，不伪装成普通 Clicked。
- `PointerCancel` 用于窗口失焦、应用切后台或手势接管时清理按压态，不产生误点击。
- `Tick` 为 Button 连发、长按、Roller、BarChart 等提供平台无关时钟；SDL 自动注入，裸机主循环传入毫秒。
- 剪贴板是 HAL 回调缝：SDL 可对接系统剪贴板，未注册后端时回退到库内缓冲。

### 内存、数值与裁减

- 内存统一经 `GY_malloc0/1`、`GY_realloc0/1`、`GY_free0/1` 适配；0/1 表示内存区，不表示清零，返回内存均为未初始化。
- 坐标以 `int16` 为主，动画/数值使用 16.16 定点，三角函数使用 Q15 LUT，常规渲染路径不要求 FPU。
- `YMGUI_ANTIALIAS` 可裁减 4bpp 灰度字体、Wu 斜线、coverage/距离场圆弧和 alpha 混合；1bpp 下强制关闭。
- Layout、CJK、TreeView、Grid、Canvas、ColorPicker、Joystick、Roller、BarChart、MsgBox、FileDialog 和动态插件均有编译期裁减路径。

## 已完成的图元与字体

- **DrawFill**：矩形填充和像素直写/混合。
- **DrawText**：UTF-8 解码、单行文本、按字节长度的 `TextN/TextWidthN`、字体 fallback 链和全局运行期 fallback。
- **DrawLine**：Bresenham 硬边直线和 Wu 抗锯齿斜线。
- **DrawImg**：`GYimg` 行主序 blit 和 colorkey 透明色。
- **DrawArc**：圆、实心圆、圆弧和粗弧环，支持 coverage 抗锯齿。

字体系统已完成 8×16 ASCII、16×16 CJK、UTF-8 整码点处理、稀疏码点索引、字体回退链和外部 flash `glyph_read`。ASCII 下划线使用独立 Y 偏移避免被字格裁掉；`YMGUI_Font_SetFallback()` 可把运行期字库灌入所有控件的回退链。

### GB2312 字模

仓库已跟踪 `tools/gb2312_glyphs.bin`。当字体、字集或光栅化参数改变时，必须同时重生成 blob 和码点索引：

```bash
sudo apt-get install python3-pil fonts-noto-cjk
python3 tools/gen_font.py \
  YMGUI/CORE/YMGUI_FontDataGB2312.c \
  --cjk --gb2312 --extern \
  --bin tools/gb2312_glyphs.bin
```

当前产物为 16×16、4bpp，共 7448 个字形；每字 128 字节，blob 共 953344 字节。字集包含 GB2312 符号/标点区、一二级汉字和 `—`、`–`、`·`。第 `i` 个排序码点对应 blob 偏移 `i * 128`。

```text
SHA-256: c2c42b2c1c2041c158a13b162549a03504202887d8179f476f9ef1a152d51316
```

## 已完成的控件

### 基础、表单与显示

- **Base Object**：容器、背景或应用自绘对象，支持树、裁剪、状态、显隐和回调。
- **Label**：居中文本、文字颜色和可选背景。
- **Button**：文字或居中图片，普通/按压配色、点击回调、可选按住连发和可关背景的纯图标模式。
- **Checkbox**：文字、选中状态和 changed 回调。
- **Switch**：布尔开关状态和 changed 回调。
- **Slider**：水平拖动、数值范围、自动钳制和 changed 回调。
- **Joystick**：`-100..100` 二维输出、圆形限位、死区、松手回中/保持、changed/released 回调和自定义皮肤。
- **Bar**：只读范围进度条和前景/背景配色。
- **Image**：居中显示非自有 `GYimg` 像素数据，支持 colorkey。
- **Arc**：范围数值映射、起止角、粗度和前景/背景色。
- **Spinner**：Tick 驱动的旋转弧，可设跨度、步进、粗度和颜色。
- **Meter**：仪表盘范围、扫描角、指针、刻度和可选数值标签。

### 文本与编辑

- **TextInput**：创建时申明容量的单行 UTF-8 编辑器；整码点光标/删除、自动水平视口、鼠标/Shift 选区、Home/End、Ctrl+A/C/X/V、剪贴板、changed 和 Enter submitted 回调。
- **EditView**：创建时申明容量的多行 UTF-8 编辑器；换行/折行、像素列对齐移动、`size_t` 索引、纵向滚动、选区、剪贴板、可关单级撤销、查找/替换/全部替换、光标行列、配色与边框。
- **TextView**：只读多行视图；可开关 `\n` 分行和宽度折行，宽度变化时重排，只绘可见行并支持拖动滚动。

### 列表、容器与复合视图

- **List**：持久子项组成的纵向列表，拖动滚动并裁到视口。
- **Chart**：网格背景、最多 4 组折线序列、值域映射、可调点数和 `SetNext` 流式左移。
- **Dropdown**：top layer 遮罩+菜单；按最长选项自适应宽度，夹在屏内，下方放不下则向上展开，支持选中回调和外部点击收起。
- **Table**：自绘表头、列、行和网格；可变列宽/行高、单行选中、行回调和纵向滚动。
- **Tabview**：顶部标签条、多页子容器、激活页切换、changed 回调和非激活页显隐管理。
- **TreeView**：轻量节点树+展平可见数组；展开/收起、缩进标记、懒加载、选中/双击/上下文回调、改名、删除子树、用户指针和滚动。
- **Grid**：行列表头、二维滚动、单格/矩形选区、Shift+方向扩选、合并/取消合并、每格对齐、每行独立高度、列宽、插入/删除行列和编辑意图回调。公式语义留在应用层。

### 绘图、选择与数据可视化

- **Canvas**：自持 `GYpx` 缓冲，1～16 整数倍缩放、平移/平移模式、屏幕↔画布坐标映射、DOWN/MOVE/UP 绘制回调和按住状态。图层和融合留在应用层。
- **ColorPicker**：HSV 饱和度-明度方块+色相条，整数 HSV↔RGB 转换，点击/拖动 changed 回调。
- **Roller**：居中高亮等高文本列表，16.16 定点缓动、跨行高亮渐变、程序选中或拖动吸附两种模式。
- **BarChart**：最多 64 柱、数值高度映射、BY_HEIGHT 竖直渐变/PER_BAR 调色板、可选峰值顶标和逐帧回落。数据分析留在应用层。

### 模态界面

- **MsgBox**：top layer 全屏遮罩+居中卡片，标题、多行正文、多按钮回调和输入模态拦截，为异步回调模型。
- **FileDialog**：`OPEN_FILE` / `SAVE_FILE` / `SELECT_DIRECTORY`；可编辑路径、TreeView 懒加载、上级/进入/刷新/新建目录、显示过滤、覆盖确认和统一结果回调。文件系统通过回调注入，库不依赖 POSIX。

完整函数签名和约束见 [API 速查](API.md)。

## 已完成的状态绑定

- `GYsubject` 支持 Int、Fixed、Bool 和 Str 状态及应用观察者。
- 绑定使用符号指针直连，无字符串路径和运行时查表；控件销毁时自动摘链。
- 单向绑定：Label、Bar、Arc、Meter。
- 双向绑定：Slider、Switch、Checkbox、TextInput。

## 已完成的插件系统

- 插件描述符包含 `struct_size`、`api_version`、ID、名称和 `init/tick/deinit` 生命周期。
- 注册表校验重复 ID、API/ABI、容量与状态；支持 Registered/Active/Failed、失败回滚、卸载后重载和安全 Reset。
- 裸机静态注册；Linux/Android 加载 `.so`，Windows 加载 `.dll`，macOS 加载 `.dylib`，可整体裁掉 OS 加载器。
- 动态插件经版本化 `YMGUI_PluginHost` 函数表使用宿主 UI 和日志，不依赖宿主导出全部 YMGUI 符号。

## 已完成的平台适配

- Linux 通过 `pkg-config` 查找 SDL2；Windows/Android 通过 SDL2 CMake target 或 `SDL2_SOURCE_DIR` 构建。
- Windows 支持 `SDL2main` 和可选静态 SDL2，不链接 Unix `libm`；Android 应用目标构建为 shared library 供 SDL Activity/Gradle 打包。
- SDL 初始化对 Window/Renderer/Texture/截图缓冲逐级检错和释放，硬件 renderer 失败后回退 software renderer。
- 鼠标、文本输入、控制键、滚轮和单指 finger 已桥接；过滤 `SDL_TOUCH_MOUSEID` 避免一次触摸双重注入。
- 触摸长按为 600ms/移动不超 10px，右键拖动阈值为 4 个逻辑像素；后台、失焦、终止会取消残留按压。
- Linux 无头模式可用 `SDL_VIDEODRIVER=dummy` 做启动、输入映射和截图验证。无头测试不代替真窗口或真机触摸验证。

详见 [跨平台移植](CROSS_PLATFORM_PORTING.md)。

- **music_player**：ffmpeg 解码、SDL2 音频、兜底旋律、LRC 歌词、Roller 同步、Slider seek 和整数 Goertzel 频段分析驱动 BarChart。

## 关键配置

- `YMGUI_COLOR_DEPTH`：`1` / `8` / `16` / `24`，CMake 默认 `16`。
- `YMGUI_ANTIALIAS`：抗锯齿；1bpp 下强制关闭。
- `YMGUI_FONT_CJK`：内建 CJK 支持和默认回退链。
- `GY_INV_MAX`：脏矩形列表容量，默认 16。
- `YMGUI_LAYOUT`、`YMGUI_TREEVIEW`、`YMGUI_GRID`、`YMGUI_CANVAS`、`YMGUI_COLORPICKER`、`YMGUI_JOYSTICK`、`YMGUI_ROLLER`、`YMGUI_BARCHART`、`YMGUI_MSGBOX`、`YMGUI_FILEDIALOG`：可裁减模块。
- `YMGUI_PLUGIN_DYNAMIC`：OS 动态插件加载；裸机默认关闭。

## 构建与验证基线

```bash
sudo apt-get install libsdl2-dev
cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
```

颜色深度必须使用独立构建目录，例如 `cmake -S . -B build-rgb888 -DYMGUI_COLOR_DEPTH=24`。`./build_all.sh` 构建根工程和 10 个独立应用；`./capture_shots.sh -b` 生成 `docs/shots/`。修改 `project_Demo` 后必须重建对应独立构建目录，顶层 build 不会自动包含它们。

仓库自检入口：`tools/check_repo.sh` 做不编译的快速检查；`tools/test.sh` 验证单个像素格式；`tools/test_matrix.sh` 默认验证 RGB565/RGB888，`--all-depths` 扩展到 1/8/16/24bpp。

2026-08-29 在 GCC 11.4.0、CMake 3.22.1 和 SDL2 2.0.20 环境完成 RGB565/RGB888 两套根工程构建，两种格式各 35/35 CTest 通过；GB2312 blob 可重现生成且与入库文件逐字节一致，无窗口字体 Demo 已验证可从 `tools/` 读取字模。

## 当前边界与未完成项

- Slider 当前是水平实现，竖直 Slider 尚未作为完整支持项验收。
- Layout 只有一次性 Stack/Align，没有持续约束、Grid 等分布局或 cross-axis stretch。
- 数据绑定没有 Dropdown/Tabview/Table index 绑定，也不做整行/列表结构绑定。
- FileDialog 不内建删除、复制、粘贴或重命名，由应用层组合。
- Canvas 不内建图层/融合，Grid 不理解公式，BarChart 不计算频谱；这些是有意的库/应用边界。
- Dropdown 收起后弹层隐藏常驻到下次展开/析构；展开 backdrop 会使整屏失效。
- Table 行使用链表；只绘可见行，但数千行的随机行查找仍是 O(n)。
- 动态插件检查不是安全沙箱，只能加载可信代码。
- 具体 MCU 的 SPI/DMA/LCD/触摸驱动未收进通用库，需按芯片和面板实现 HAL。
