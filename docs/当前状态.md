# YMGUI 当前状态

> 更新日期：2026-10-08
> 本文是 历卷 DEVLOG 的去时间线汇总：列出已完成的能力、当前规模、验证基线和已知边界。与历史记录冲突时，以代码、测试、CMake 和本文为准。

## 项目定位与规模

仓库采用 [Apache License 2.0](../LICENSE)。根 README 的 demo 展示区每个 demo 保留一张代表性运行图，音乐工坊使用当前鼓机与多轨编排全景；同时提供可点击的本地协议徽章和许可说明；第三方依赖、音源、曲库素材及参考软件按各自附带的许可与来源说明处理。

YMGUI 是面向嵌入式和裸机的跨平台 GUI 库，使用 C99 + GNU 扩展。核心路线是软件光栅化、保留模式对象树、脏矩形和 band 分块刷新。桌面端通过 SDL 充当假 LCD，真机通过 `flush_cb` 接入 LCD/framebuffer；控件和渲染核心不依赖 SDL、GPU 或 OS 消息泵。

- `YMGUI/` 库本体共 11 个层、56 个 `.c` 文件。
- 27 个具名控件，加 base 对象/容器共 28 类 UI 对象。
- 5 类核心图元：填充、文字、直线、图片和圆/弧。AA 斜线的负斜率和负坐标定点换算使用 64 位乘法，避免负数左移的未定义行为，绘图回归覆盖两种情况。
- 根工程 38 个 CTest，`Demo/` 下 49 个 `demo_*.c`，`project_Demo/` 下 15 个完整应用。
- framebuffer 支持 1bpp、8 位灰度、RGB565 和 RGB888，CMake 默认 RGB565。

## 目录与分层

```text
YMGUI/
  CONFIG/   公共类型、颜色/定点宏、裁减开关、内存适配
  DEBUG/    assert 和日志
  COMMON/   几何与 Q15 三角查表
  OPOBJ/    对象树、生命周期和 top layer
  CORE/     软件光栅化、字体和图像图元
  GUI/      失效区、分块刷新、事件、焦点和布局
  ANIM/     context 级 UI 属性补间、缓动、取消和对象生命周期联动
  HAL/      显示、输入、时钟和剪贴板接口
  WIDGET/   控件
  STATE/    状态容器、观察者和控件绑定
  PLUGIN/   静态插件注册表和可选 OS 动态加载器
```

`YMGUI/` 是可移植库本体。`SDL_LCD/` 是 Linux/Windows/Android 假 LCD 和输入桥接；`Demo/` 是单控件/机制演示；`project_Demo/` 是独立完整应用；`tests/` 是行为规格和回归测试。

`extern_lib/` 存放供 `project_Demo/` 应用按需使用的第三方依赖；当前 `FFmpeg/` 由视频剪辑器使用，`GeneralUser-GS/` 提供音乐工坊的13 类乐器采样 bank、七种鼓声 WAV 和来源许可，`BodyPercussion/` 提供 CC0 实录拍手/响指。编译产物放在对应应用的 build 目录，该目录不属于 YMGUI 核心库的移植范围。

`参考/` 提供音乐制作软件体验入口：LMMS v1.2.2、Hydrogen 1.2.6 和 Ardour 9.8 已在本机从源码编译、安装并打开示例。LMMS / Hydrogen 分别完成约 365 秒和 25 秒的非静音 WAV 导出；Ardour 完成双轨音频导入、保存重开、播放电平和约 25 秒的 48 kHz 立体声混音导出验证。LMMS / Hydrogen 使用 PulseAudio；Ardour 本机验证使用 ALSA，并编入 PulseAudio / JACK 及 LV2 / Linux VST / VST3 支持，未运行上游完整测试套件。整个 `参考/` 目录仅保留本机，由根 `.gitignore` 排除，包含源码、依赖、构建、安装、配置、音频、说明、脚本、依赖清单及 Ardour 的 UTF-8 模板替换补丁；`build/music-reference` 是解决旧版构建脚本中文路径问题的符号链接。Ardour 使用独立 Waf build/install 目录和 XDG 配置，补丁仅解决中文路径生成脚本失败。它们尚未集成进 YMGUI，也不增加 `project_Demo` 数量，本机使用说明保留在 `参考/README.md`。

`tools/` 放置字体生成器、GB2312 外部字模 blob 和仓库级检查/测试脚本，不随 `YMGUI/` 移植到 MCU。

`sdk/` 是独立二进制库的构建、打包和接入说明；生成目录为 `build/sdk/YMGUI_libs/`。`SDL_LCD/` 仍只负责平台适配，打包流程不放在该目录。

构建顶层默认按用途分为色深目录、`sdk/`、`checks/`、`logs/`：常规 Demo/应用保持 `build/rgb565`、`build/rgb888`；SDK 中间文件在 `build/sdk/work`，专项裁剪/临时验证在 `build/checks`，日志在 `build/logs`。全量构建自动保存分色深日志，SDK 编译/包外接入日志集中到 `build/logs/sdk`；`sdk/verify.sh` 复验最终压缩包、二色深示例及动效链接，退出自动清理本次临时目录，失败校验也不残留。仅清理本轮确认的旧生成目录，不自动迁移未知文件或搬动 CMake 缓存；详见 [构建目录说明](BUILD_LAYOUT.md)。

`releases/` 存放随仓库提交的预编译压缩包与 SHA-256 文件；`./sdk/build.sh --release` 验收后更新该目录，普通打包只更新被 Git 忽略的 `build/`。当前分发包为 Linux x86_64，详见 [分发说明](../releases/README.md)。

## 已完成的基础能力

### 显示与渲染

- `GYdisp.flush_cb` 是唯一必须的显示硬件接口，接收区域和连续像素块。
- draw buffer 可小于整屏，脏区会被切成 band 逐块渲染和 flush。
- 支持多脏矩形；超过 `GY_INV_MAX` 后退化为合并包围盒，无脏区时 `YMGUI_Refresh()` 空转返回。
- 支持单缓冲同步 flush，也支持 `buf1/buf2` 乒乓和 DMA 异步重叠；中断通过 `YMGUI_Disp_FlushReady()` 通知完成。
- `frame_done_cb` 在一帧的所有脏区/band 完成后通知桌面后端 Present，真实 LCD 可不注册。
- SDL 适配提供 `SDL_LCD_WindowId()` 查询当前窗口 ID，`SDL_LCD_SetTitle()` 设置标题；无窗口时分别返回 0 和失败，头文件不暴露 SDL 结构体。
- `YMGUI_COLOR_DEPTH=1/8/16/24` 对应单色、灰度、RGB565 和字节顺序 R/G/B 的 RGB888。`GYpx` 是公开 ABI，库与应用必须同深度构建。

### 对象、裁剪与布局

- 保留模式父子/兄弟树，支持递归级联释放、显隐、状态位、自定义绘制和事件回调。
- 命中测试和绘制共用叠放顺序；子节点可裁剪到父视口。
- `top_layer` 是独立全屏层，用于 Dropdown、MsgBox、FileDialog 和应用自定义浮层。
- 通用滚动捕获、子裁剪、绝对坐标和对象失效已落地。
- 可裁减的一次性 `Stack`/`Align` 布局助手只计算并写坐标，不增加每对象运行时 RAM。

### 输入、事件与焦点

- 指针事件包括按下、按住、抬起、移出抬起、点击和双击，具有 pressed-object 捕获语义。
- 键盘支持可打印字符、方向、Backspace、Delete、Enter、Home/End、Tab 和 Ctrl/Shift 组合。
- `YMGUI_FocusNext()` 按对象树前序轮转焦点，跳过 Hidden 子树并末尾回卷。编辑控件先消费 Tab，未消费时才轮转焦点。
- 滚轮保留横纵有符号增量，派发给指针位置命中的对象。
- 右键短点是一次性 `ContextRequested`；右键拖动和触摸长按后拖动具有 Requested/Dragging/Released/Cancelled 独立捕获链，不伪装成普通 Clicked。
- `PointerCancel` 用于窗口失焦、应用切后台或手势接管时清理按压态，不产生误点击。
- `Tick` 为 Button 连发、长按、Roller、BarChart 和 context 动画调度器提供平台无关时钟；SDL 自动注入，裸机主循环传入毫秒。
- `ANIM` 提供位置、尺寸、背景色、滚动量和通用整数值补间，支持延迟、完成/取消回调、同对象同属性平滑替换以及对象析构自动取消；内建曲线使用 16.16 定点，亦可注入外部 rate callback。`YMGUI_ANIM=OFF` 可在根工程和应用源码构建中裁掉该层、HAL 动画 Tick 调用、context 的三个管理指针及对应 Demo/测试目标；普通事件 Tick 仍工作。源码移植可在配置头设 `YMGUI_ANIM=0`，预编译 SDK 必须匹配打包时的开关。
- YMGUI 核心与二十个动效场景均不依赖 YMANIM；仓库不再保留原先的 `integrations/YMANIM/` 联动示例。`YMGUI_Anim_SetRateCallback` 仍允许应用自行提供外部缓动采样。
- `Demo/` 提供二十个独立交互动效场景：抽屉导航、top layer 模态弹窗、错峰卡片重排、数值驱动的进度反馈、页签切换、折叠面板、通知堆叠、滚动视口、主题过渡、焦点跟随、表单校验、批量操作栏、列表增删重排、拖拽卡片吸附、按钮提交反馈、加载态切换、侧边详情、下拉刷新、轮播吸附和 Canvas 播放头。十九个只使用标准 YMGUI 对象/控件；Canvas 仅用于播放头，避免把示例集变成 YMANIM 场景展示。新场景的插入/删除使用真实对象生命周期；拖拽场景使用现有指针捕获，松手后交给 ANIM 补间。动效 Demo 的 SDL 窗口使用 framebuffer 原生 1:1 显示；基础 `demo_anim` 同样为 1:1，且不重复手动推进 SDL Tick。详见 [动效 Demo 说明](../Demo/ANIM_DEMOS.md)。
- 剪贴板是 HAL 回调缝：SDL 可对接系统剪贴板，未注册后端时回退到库内缓冲。

### 内存、数值与裁减

- 内存统一经 `GY_malloc0/1`、`GY_realloc0/1`、`GY_free0/1` 适配；0/1 表示内存区，不表示清零，返回内存均为未初始化。
- 坐标以 `int16` 为主，动画/数值使用 16.16 定点，三角函数使用 Q15 LUT，常规渲染路径不要求 FPU。
- `YMGUI_ANTIALIAS` 可裁减 4bpp 灰度字体、Wu 斜线、coverage/距离场圆弧和 alpha 混合；1bpp 下强制关闭。
- Layout、CJK、TreeView、Grid、Canvas、ColorPicker、Joystick、Roller、BarChart、MsgBox、FileDialog 和动态插件均有编译期裁减路径。

## 已完成的图元与字体

- **DrawFill**：矩形填充和像素直写/混合。
- **DrawText**：UTF-8 解码、单行文本、按字节长度的 `TextN/TextWidthN`、字体 fallback 链和全局运行期 fallback。
- **DrawLine**：Bresenham 硬边直线和 Wu 抗锯齿斜线。
- **DrawImg**：`GYimg` 行主序 blit 和 colorkey 透明色。
- **DrawArc**：圆、实心圆、圆弧和粗弧环，支持 coverage 抗锯齿。

字体系统已完成 8×16 ASCII、16×16 CJK、UTF-8 整码点处理、稀疏码点索引、字体回退链和外部 flash `glyph_read`。ASCII 下划线使用独立 Y 偏移避免被字格裁掉；`YMGUI_Font_SetFallback()` 可把运行期字库灌入所有控件的回退链。

### GB2312 字模

仓库已跟踪 `tools/gb2312_glyphs.bin`。当字体、字集或光栅化参数改变时，必须同时重生成 blob 和码点索引：

```bash
sudo apt-get install python3-pil fonts-noto-cjk
python3 tools/gen_font.py \
  YMGUI/CORE/YMGUI_FontDataGB2312.c \
  --cjk --gb2312 --extern \
  --bin tools/gb2312_glyphs.bin
```

当前产物为 16×16、4bpp，共 7672 个字形；每字 128 字节，blob 共 982016 字节。字集包含 GB2312 符号/标点区、一二级汉字，以及输入法使用的货币、版权、破折号、数学、角标、序号、拼音和箭头补充符号。第 `i` 个排序码点对应 blob 偏移 `i * 128`。


## 已完成的控件

### 基础、表单与显示

- **Base Object**：容器、背景或应用自绘对象，支持树、裁剪、状态、显隐和回调。
- **Label**：居中文本、文字颜色和可选背景。
- **Button**：文字或居中图片，普通/按压配色、点击回调、可选按住连发和可关背景的纯图标模式。
- **Checkbox**：文字、选中状态和 changed 回调。
- **Switch**：布尔开关状态和 changed 回调。
- **Slider**：水平拖动、数值范围、自动钳制和 changed 回调。
- **Joystick**：`-100..100` 二维输出、圆形限位、死区、松手回中/保持、changed/released 回调和自定义皮肤。
- **Bar**：只读范围进度条和前景/背景配色。
- **Image**：居中显示非自有 `GYimg` 像素数据，支持 colorkey。
- **Arc**：范围数值映射、起止角、粗度和前景/背景色。
- **Spinner**：Tick 驱动的旋转弧，可设跨度、步进、粗度和颜色。
- **Meter**：仪表盘范围、扫描角、指针、刻度和可选数值标签。

### 文本与编辑

- **TextInput**：创建时申明容量的单行 UTF-8 编辑器；整码点光标/删除、自动水平视口、鼠标/Shift 选区、Home/End、Ctrl+A/C/X/V、剪贴板、changed 和 Enter submitted 回调。
- **EditView**：创建时申明容量的多行 UTF-8 编辑器；换行/折行、像素列对齐移动、`size_t` 索引、纵向滚动、选区、剪贴板、可关单级撤销、查找/替换/全部替换、光标行列、配色、边框和可配置四边内边距；`YMGUI_EditView_InsertText()` 可在当前光标插入 UTF-8 文本或替换选区，并纳入撤销。
- **TextView**：只读多行视图；可开关 `\n` 分行和宽度折行，宽度变化时重排，只绘可见行并支持拖动滚动。

### 列表、容器与复合视图

- **List**：持久子项组成的纵向列表，拖动滚动并裁到视口。
- **Chart**：网格背景、最多 4 组折线序列、值域映射、可调点数和 `SetNext` 流式左移。
- **Dropdown**：top layer 遮罩+菜单；按最长选项自适应宽度，夹在屏内，下方放不下则向上展开，支持选中回调和外部点击收起。
- **Table**：自绘表头、列、行和网格；可变列宽/行高、单行选中、行回调和纵向滚动。
- **Tabview**：顶部标签条、多页子容器、激活页切换、changed 回调和非激活页显隐管理。
- **TreeView**：轻量节点树+展平可见数组；展开/收起、缩进标记、懒加载、选中/双击/上下文回调、改名、删除子树、用户指针和滚动。
- **Grid**：行列表头、二维滚动、单格/矩形选区、Shift+方向扩选、合并/取消合并、每格对齐、每行独立高度、列宽、插入/删除行列和编辑意图回调。公式语义留在应用层。

### 绘图、选择与数据可视化

- **Canvas**：自持 `GYpx` 缓冲，1～16 整数倍缩放、平移/平移模式、屏幕↔画布坐标映射、DOWN/MOVE/UP 绘制回调和按住状态。图层和融合留在应用层。
- **ColorPicker**：HSV 饱和度-明度方块+色相条，整数 HSV↔RGB 转换，点击/拖动 changed 回调。
- **Roller**：居中高亮等高文本列表，16.16 定点缓动、跨行高亮渐变、程序选中或拖动吸附两种模式。
- **BarChart**：最多 64 柱、数值高度映射、BY_HEIGHT 竖直渐变/PER_BAR 调色板、可选峰值顶标和逐帧回落。数据分析留在应用层。

### 模态界面

- **MsgBox**：top layer 全屏遮罩+居中卡片，标题、多行正文、多按钮回调和输入模态拦截，为异步回调模型。
- **FileDialog**：`OPEN_FILE` / `SAVE_FILE` / `SELECT_DIRECTORY`；可编辑路径、TreeView 懒加载、上级/进入/刷新/新建目录、显示过滤、覆盖确认和统一结果回调。可选 `SetTranslator` 翻译按钮及显示状态文案，路径、文件名和 `GetStatus` 状态键保持原值，未设置时仍显示默认英文。文件系统通过回调注入，库不依赖 POSIX。

完整函数签名和约束见 [API 速查](API.md)。

## 已完成的状态绑定

- `GYsubject` 支持 Int、Fixed、Bool 和 Str 状态及应用观察者。
- 绑定使用符号指针直连，无字符串路径和运行时查表；控件销毁时自动摘链。
- 单向绑定：Label、Bar、Arc、Meter。
- 双向绑定：Slider、Switch、Checkbox、TextInput。

## 已完成的插件系统

- 插件描述符包含 `struct_size`、`api_version`、ID、名称和 `init/tick/deinit` 生命周期。
- 注册表校验重复 ID、API/ABI、容量与状态；支持 Registered/Active/Failed、失败回滚、卸载后重载和安全 Reset。
- 裸机静态注册；Linux/Android 加载 `.so`，Windows 加载 `.dll`，macOS 加载 `.dylib`，可整体裁掉 OS 加载器。
- 动态插件经版本化 `YMGUI_PluginHost` 函数表使用宿主 UI 和日志，不依赖宿主导出全部 YMGUI 符号。

## 已完成的平台适配

- Linux 通过 `pkg-config` 查找 SDL2；Windows/Android 通过 SDL2 CMake target 或 `SDL2_SOURCE_DIR` 构建。
- Windows 支持 `SDL2main` 和可选静态 SDL2，不链接 Unix `libm`；Android 应用目标构建为 shared library 供 SDL Activity/Gradle 打包。
- SDL 初始化对 Window/Renderer/Texture/截图缓冲逐级检错和释放，硬件 renderer 失败后回退 software renderer。
- 鼠标、文本输入、控制键、滚轮和单指 finger 已桥接；过滤 `SDL_TOUCH_MOUSEID` 避免一次触摸双重注入。
- SDL 桥接会为 Shift/Ctrl/Alt/Caps 注入原始按下/抬起状态，失焦、后台和退出时清除残留修饰态；可选全局按键过滤器允许输入法在焦点控件前消费实体键，并复用屏幕键盘回调和状态。
- 触摸长按为 600ms/移动不超 10px，右键拖动阈值为 4 个逻辑像素；后台、失焦、终止会取消残留按压。
- Linux 无头模式可用 `SDL_VIDEODRIVER=dummy` 做启动、输入映射和截图验证。无头测试不代替真窗口或真机触摸验证。

详见 [跨平台移植](CROSS_PLATFORM_PORTING.md)。

## 已完成的完整应用

## AT32 移植回流到通用库

已从用户提供的 AT-SURF-F437 手机移植吸收通用机制，源码与测试落在 `YMGUI/` 和 `tests/test_port.c`，不依赖 AT32 SDK、FatFs、Keil 或 SDRAM 地址：

- 脏矩形在合并前裁到显示范围，避免离屏矩形把两个可见更新桥接为大包围盒；对象标脏沿祖先检查 Hidden 和 ClipChildren。提供可见旧区域标脏、越界自绘/子树的保守绘制范围标脏和主动合并脏区接口。
- band 行数先在 uint32 中钳到脏区高度，再转 GYcoord；整屏 buffer 刷新 1/3/5 像素宽脏区不会因 int16 转换溢出退化成逐行刷新。
- 内置动画的移动、尺寸、背景色和滚动在量化后值未变时跳过标脏，时间与完成逻辑继续推进；含越界自绘/子树的移动和尺寸变化使用保守范围擦除旧像素。
- 可选遮挡计划 `YMGUI_OCCLUSION=1`：逆绘制顺序求不透明矩形并集，再按原顺序绘制；完整遮挡跳过，有边界承诺的回调最多拆成四个可见片段。base 填充自动识别，其他回调通过 `GY_STATE_OpaqueRect` / `GY_STATE_BoundedDraw` 显式承诺。128 项计划、64 覆盖矩形或碎片容量溢出时保守回退，不漏绘；默认关闭，不保留计划工作区。开启时使用固定全局工作区（主机默认坐标约 9.5 KiB），只支持同一 UI 线程顺序刷新，回调不得递归 Refresh 或修改绘制树。
- 字形先解析实际回退字体、再裁到 surface.clip 与 buf_area；完全不可见时保留 advance 且不读外部存储。RGB565 填充和 4bpp 字形使用与原结果一致的整数混合/背景缓存；不透明填充以 memcpy 批量写入，遵守对齐和有效类型规则。
- 无透明色图片逐行拷贝；同尺寸缩放直接 blit，最多 320 个可见列预计算最近邻源坐标，更宽区域继续原采样路径；所有写入先裁到真实 buffer。Image 的 FIT/FILL 不再填充随后被不透明图片完整覆盖的背景，仅填 letterbox；透明色图片仍先完整绘背景。
- `YMGUI_Inject_Touch` 接收完整触点帧和稳定 ID（通用容量默认5，可一致配置1–255），监听器可处理多指。普通控件仍只收单主指针；第二指加入、ID 被替换或无效帧取消原捕获，全部抬起前不恢复点击，避免误触。SDL 后端把 device/finger 对映射为稳定 ID，派发完整多点帧；保留单指长按，双指取消点击/上下文捕获，失焦/退出清理。SDL 合成鼠标事件不会重复派发。
- TextInput/EditView 清理折返后塌缩及越界选区锚点，插入/删除后重置锚点；静止 Pressing 不创建选区。修复中文逐字节输入替换刚输入字符、连续退格使用旧锚点导致越界的问题。
- `YMGUI_CLIPBOARD_DYNAMIC=1` 首次复制才从 `GY_malloc1` 分配库内剪贴板；空状态/分配失败返回空串，`YMGUI_Clipboard_Clear` 释放缓冲。默认仍是静态 32 KiB，可用 `GY_CLIP_MAX` 调整。系统后端继续优先。

- `YMGUI_TextActions_Update` 按需启用单行/多行编辑器共用的复制/剪切/粘贴/全选菜单，长按/选区/右键入口，适应根宽和可用底边，提供翻译回调；目标销毁/隐藏/失焦及禁用时清理。调用方模态或应用状态变化须禁用；普通应用默认不创建菜单。
- `YMGUI_FontCache` 提供参数化 memory0 FIFO 与 memory1 热 LRU 字模缓存，短读不污染屏幕，戳回绕重置，分配失败降级。phone_locale 用 32/128 项，验证文件长度/两端读取，Shutdown 恢复旧 fallback 并释放文件/缓存。
- `YMGUI_Resource` 统一 open/read_at/close 后端；文件保留打开时的回调副本，整文件 Load 使用 memory1 并处理短读。默认 stdio 可用 `YMGUI_RESOURCE_STDIO=OFF` 关闭，FatFs 等后端由目标项目适配；phone 字库及共用输入法词典均接入。输入法候选指针池/组合状态改为 memory1 动态申请与清理。
- `YMGUI_Arena` 从调用方存储区建立分裂/合并堆，提供 realloc 失败保留/used/peak/最大连续空闲；`YMGUI_Bus` 提供 GUI/Worker/LCD 所有权、critical/ISR 回调、延期与违规统计；`YMGUI_StagedFlush` 把外部像素经调用方片内缓冲同步分块发送，禁止 ISR 复制，发送回调错误/超时返回前必须停止 DMA。这些模块需平台包住完整 UI/资源访问，不自动启用并行外存访问。
- `YMGUI_Inject_TouchCancel` 提供跨平台触摸取消。具体型号协议由目标项目的适配层处理，本仓库不收录型号实现；`YMGUI_ScaleBilinear.h` 提供双线性/最近邻轴表，`YMGUI_TouchGesture.h` 提供屏幕距离整数计算。
- `phone_runtime.h` 统一 Init/Step/Pump/Key/Shutdown，独立 `YMGUI_PORTABLE_APP=ON` 生成无 SDL 静态 phone 库；显式 display/刷新/过渡/光标回调，显示缓冲归调用方。手机 CMake 默认开启遮挡及动态剪贴板，通用根工程仍默认关闭。
- 仓库不保留板级源码、型号解包、SDK/Keil配置、调试脚本及原固件日志副本；它们仍在原移植工程。已验证的通用机制与应用优化保留在库、SDL适配和共用phone中。新平台实现显示、输入、资源、内存及同步回调即可接入；本轮无固件烧录。

两项新配置在根工程和独立应用公共 CMake 中均默认 OFF，可传同名 `-D...=ON`；直接嵌入源码时定义同名宏为 1。对象和显示结构体没有增加字段。`releases/` 已更新，包含本次通用 API 和修复，固定配置详见分发说明。吸收范围、板级经验与验证命令见 [AT32 回流说明](AT32_PORT_REVIEW.md)。第二轮补齐文字菜单、字模缓存、资源后端、堆/总线/发送/触点工具，并合并 phone 应用优化；具体 DMA/扫描同步由目标项目适配，来源经验可在原移植工程追溯。

## 当前边界与未完成项

- Slider 当前是水平实现，竖直 Slider 尚未作为完整支持项验收。
- Layout 只有一次性 Stack/Align，没有持续约束、Grid 等分布局或 cross-axis stretch。
- ANIM 当前是单段补间器，尚无声明式 sequence/parallel、弹簧物理或控件透明度/通用变换矩阵；`THERE_AND_BACK` 按定义在终点回到起值。完整 YMANIM 适配依赖浮点、libm 和整块 RGB888 离屏缓冲，只适合可选的资源充足目标。
- 数据绑定没有 Dropdown/Tabview/Table index 绑定，也不做整行/列表结构绑定。
- FileDialog 不内建删除、复制、粘贴或重命名，由应用层组合。
- Canvas 不内建图层/融合，Grid 不理解公式，BarChart 不计算频谱；这些是有意的库/应用边界。
- Dropdown 收起后弹层隐藏常驻到下次展开/析构；展开 backdrop 会使整屏失效。
- Table 行使用链表；只绘可见行，但数千行的随机行查找仍是 O(n)。
- 动态插件检查不是安全沙箱，只能加载可信代码。
- 具体 MCU 的 SPI/DMA/LCD/触摸驱动未收进通用库，需按芯片和面板实现 HAL。

## 视频工程回流：少拷贝与遮罩

黑色半透明矩形填充在RGB565/RGB888中自动使用局部分量表，支持任意opa并保持原混合舍入。表空间分别96/256字节，不申请堆或保留全局大表；裁剪后少于256像素保留原路径，RGB565均匀采样时保留重复像素缓存。`YMGUI_BlackLutEnabled`默认1，可关闭该路径作对照；`YMGUI_BlendOptimizeEnabled=0`关闭全部填充混合优化。诊断开关由同一UI线程设置。

`YMGUI_Image_InvalidateContent(img)`用于源尺寸/布局/模式不变、只在原像素存储上更新内容：按NONE/FIT/FILL实际绘制范围并结合祖先可见性标脏，FIT黑边不重复发送。源几何、布局、背景或缩放模式改变时使用原setter/完整失效；无有效源时完整标脏。对象仍借用GYimg及像素，调用方保证它们在刷新期间有效且不被解码器覆盖。

`YMGUI_StagedFlushAuto(bus,area,pixels,staging,capacity,accessible,send,user)`提供同步直发优先路径。accessible在GUI持有资源、非ISR时判断后端是否能发送整个紧凑源区域；接受时允许staging=NULL/capacity=0，并一次调用send；拒绝或回调NULL时保持原分块中转。send返回前必须完成或中止传输，包括错误，之后资源归还GUI。回调只表达后端能力，不依据固定地址，也不自动承诺异步零拷贝。

播放器现在直接将部分读入积累到空闲队列尾槽，完整后发布；移除一份整帧缓冲和入队复制，保留稳定显示缓冲及音频主钟选帧，seek复用队列。解码器输出与GUI合成之间必要的拷贝仍保留。JPEG/FEDC表复用尚未回流：当前来源缺失解码依赖，不能重新验证；旧应用按钮缓存正常SetText失效不完整，未直接复制为通用缓存。

效率验证入口为 [视频基准](../tools/benchmarks/README.md)。四步均有像素/数据一致性及时间、流量或内存对照，主机结果不能当作板上帧率。

本轮Linux x86_64/GCC 11.4对照：320×240多色黑色遮罩RGB565约2.62倍、RGB888约2.51倍；RGB565纯色大区域持平。320×240播放器节省150/225 KiB及一次整帧复制，seek不重新分配帧；可直发后端省掉一帧中转，320×480 FIT样例刷新像素减半。完整测量及小区域开销见基准说明。双色深根CTest各38/38，播放器帧管道1/1及核心/管道ASan/UBSan通过。Linux x86_64 SDK已同步重编译并验证，包含三个新增核心入口；包内BUILD_INFO记录4b78c7a基线加本轮源码摘要，具体平台仍从源码编译。

本轮不新增字模缓存：当前FontCache已支持参数化缓存，phone使用32项FIFO加128项热LRU；旧视频工程的缓存方案以当前实现为基准对照，不重复导入。
