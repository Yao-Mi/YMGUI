## 第 139 轮：吸收 AT32 手机移植的通用修复与优化

- 背景：用户提供 `/media/yaomi/YMGUI/ymgui_phone`，希望把在 AT32 真机移植中有用的经验吸收回库。先对照当前 README、现状、AI 指南与源码，保留工作区已有修改，原工程只读；移植中的板上记录视为来源经验，不冒充本轮真机验收。
- 改动：合并前离屏裁剪、祖先 Hidden/ClipChildren 标脏、可见旧区域与保守子树绘制范围接口、主动脏区合并、band 行数 uint32 钳制；动画量化值不变时避免无效标脏，越界自绘和子树移动采用保守擦除。新增可裁减遮挡计划，完整遮挡跳过、最多四段可见 clip，按原 painter 顺序执行；base 自动识别，其他回调显式承诺 OpaqueRect/BoundedDraw，容量不足保守回退。
- CORE：外部字形读取前先裁剪，保留 fallback advance；RGB565 填充/4bpp 字形的等价整数混合与背景缓存；不透明 memcpy 批量填充、图片行拷贝、同尺寸 blit 与源列缓存，Image 只填不被不透明图片覆盖的 letterbox。图片始终裁到真实 buffer；列缓存使用 GYcoord。没有引入对 uint16 buffer 的 uint32 别名写入或 CPU 未对齐假设。
- 输入与资源：HAL 增加完整五触点帧和监听器，稳定 ID、第二指/无效帧/ID 替换取消捕获，全部抬起前抑制普通点击；切换 ctx 取消 Touch 捕获，回调切换 ctx 后不向新 UI 分发旧帧。两个编辑器修复塌缩/越界选择锚点、UTF-8 输入丢字和连续退格越界，静止 Pressing 不建选区。剪贴板可按需从内存区 1 分配，Clear 释放及清空后端；默认仍静态缓冲。
