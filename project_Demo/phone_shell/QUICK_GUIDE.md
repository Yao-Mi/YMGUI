# 快捷设置注册与扩展

控制中心不是按功能 ID 写点击分支：`phone_quick.c` 负责注册、查找与自动排位，`phone_shade.c` 只负责呈现、手势、分页和回调分发；内置设备演示状态独立放在 `phone_quick_builtin.c`。内置项各有自己的描述符，共用设备状态是为了 Wi-Fi/飞行模式等联动，不代表新功能必须塞入内置分支。

## 新增功能

1. 把 [quick_example.c.in](quick_example.c.in) 复制为 `quick_example.c`，实现私有状态与回调。
2. 在 [phone_quick_catalog.def](phone_quick_catalog.def) 需要的位置加入 `PHONE_QUICK(example, quick_example)`。
3. 重新构建。CMake 自动收集源文件并去重；描述符、布局、分页、点击分发无需另改。

清单第一项为描述符后缀，第二项为本目录源文件名（不含 `.c`）。可多项共用一个源文件，也可每项独立文件。调换清单行就调换显示顺序，不按 key 或名称排序。

`PhoneQuick` 的字段：

| 字段 | 契约 |
| --- | --- |
| `key` | 唯一非空稳定标识，用于查找，不影响排序 |
| `title` | 非空 UTF-8 文案；统一正文档，英文不再用偏小的小字档；建议三字以内，超长按完整字符裁切且绘制不越界 |
| `active()` | 可选、只读状态查询；非零高亮，空回调表示一次性动作 |
| `activate()` | 必需的点击回调；可以操作自身状态或调用宿主服务 |
| `draw_icon()` | 可选的图标绘制，缺省齿轮；传当前卡片背景色，绘制裁剪到卡片 |

也可以在面板初始化前调用 `PhoneQuick_Register(&descriptor)`。描述符和字符串必须在整个应用期间有效；重复 key、空字段/缺回调、超过 32 项或面板构建后注册均返回失败。清单注册失败会阻止正常启动并报告问题，不能静默产生错位项。

每页 8 项，4 列×2 行，严格按注册顺序排位；第 9 项自动进入下一页，最多 32 项/4 页。通知和亮度区不被扩展项挤走。面板显示时检测开关状态变化，只使变化的卡片失效；点击后统一刷新。亮度是固定公共滑块，不属于方块注册表。

边界：这是启动期静态注册，不是运行时安装、卸载、拖动排序或跨进程插件。当前内置项仍是本地演示状态。面板入口动作和桌面图标排序是两套独立模型；ANIM OFF 不影响回调、布局、翻页和滑块。

验证：注册表测试覆盖乱序 key 的注册顺序、重复/无效项、32 项边界、四页坐标和回调；手机自检额外注册一个第 9 项，实际点按第二页并验证回调、页边界和返回第一页。正式清单仍是 8 项。
