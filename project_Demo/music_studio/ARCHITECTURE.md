# music_studio 架构与 AI 开发说明

先阅读仓库 [AI 使用指南](../../docs/AI_GUIDE.md)。音乐业务放在本应用内；轨道、音符、音频采样和混音不进入 YMGUI 控件核心。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `model/project.h`、`project.c` | 有界工程值类型、96 PPQ 时间、轨道/片段/音符操作、验证、32 步快照历史、波形摘要 |
| `model/storage.c` | 版本化单文件工程、小端序字段与 float PCM、容量和有限数值校验、候选加载、原子保存；不依赖 SDL/GUI |
| `audio/audio.c` | 内置鼓声 PCM 加载、片段试听副本、FFmpeg 子进程解码、统一混音、WAV 导出、SDL 声卡队列与可闻时钟 |
| `audio/sample_bank.c` | 所有乐器的 bank 校验加载、就近音区、PCM 插值移调、自然衰减或交叉淡化循环 |
| `examples/sound_demo.c` | 可选 `music_sound_demo` 生成全采样乐器工程与拍手/响指试听 |
| `app/studio.h`、`actions.c` | 应用状态、编辑命令、历史入口、选中项、播放控制和变更后的界面同步 |
| `ui/workspace.c` | 中文工作台、按钮、名称输入、属性滑块、动态页签控件 |
| `ui/timeline.c` | 素材库、轨道头、时间标尺、片段/波形绘制、吸附、拖动与裁剪 |
| `ui/editors.c` | 鼓机、力度区、钢琴卷帘、混音器的绘制与交互 |
| `ui/dialogs.c` | POSIX 文件系统适配、中文翻译、覆盖/丢弃确认、后台文件任务的启动和结果回收 |
| `examples/epic_demo.c` | 可选 `music_epic_demo` 目标生成六小节交响采样小样，输出普通工程与 WAV |
| `tools/build_library.py`、`library/` | 离线 MIDI 曲库转换、配器配置、原始来源/许可/校验及可编辑工程；不进入运行时导入路径 |
| `main.c` | 显示/字库/音频生命周期、桌面快捷键、主循环、自动恢复、命令行入口 |

自绘视图使用 base 对象和 YMGUI 的 surface 图元；通用按钮、标签、滑块、音色下拉框、输入框与模态对话框继续使用现成控件。不要覆盖控件私有 `user_data`；自绘 base 可以存应用指针，按钮通过应用表查找命令。标签容量仅在本独立构建中设为 256 字节以容纳中文操作说明。

## 工程与编辑语义

面向用户的流程和快捷键见 [编辑操作指南](docs/编辑操作.md)。维护交互时同步该指南，并区分视图状态、选择状态与工程时值。

- `MsSong` 是不含指针的工程快照。轨道和片段用有界数组，片段引用轨道与节奏型/素材下标。删除或移动轨道必须更新片段引用；打开/新建/历史恢复时清理失效的选择与剪贴板。
- 一个四分音符为 96 tick，鼓机与编排基础步进为 24 tick。钢琴的编辑步长另由 `MsApp.note_grid` 选择 24/12/6/32/16/8/1 tick，对应直分、三连音和自由模式；关闭吸附时有效步长为 1 tick。此项仅为会话内编辑偏好，不进入 MsSong 或历史。节奏型为 16 或 32 步，片段引用它并按周期重复。独立副本复制节奏型再替换当前片段引用。
- 视图缩放与音乐时值分离：编排区使用 `zoom/scroll`（0.12–12 像素/tick），下方使用 `editor_zoom/editor_scroll`（整段视图的 1–16 倍及浮点 tick 偏移）。Ctrl＋滚轮缩放鼠标所在区域，保留指向的 tick 后钳制视口；时间线起点为整数 tick，锚点误差最多约半 tick。下方 Shift＋滚轮/横向滚轮平移，绘制、命中、框选、创建和拖动共用缩放后坐标，键盘/鼓名固定且网格裁剪在右侧区域。修改片段长度或切换片段时钳制到合法范围；视图参数仅驻会话，不改变模型、历史、脏标记或音频快照。忙碌与拖动期间仍维护 Ctrl/Shift 抬起状态，SDL 失焦沿用修饰键取消注入。应用矩形绘制先在整数范围裁剪，再转 GYcoord，避免大时间坐标/宽度在 16 位下回绕。
- 钢琴框选使用 `MsApp.select_notes`、音符下标位图与所属片段记录；选择、框选开关不进入 `MsSong`、不记历史、不触发音频重启。`drag=7` 表示矩形框选，只命中当前可见八度并使用同一最小 3 像素宽度；PointerCancel 恢复之前的选区，正常移出释放则按网格边界完成选择。`drag=6` 在框选模式中以手势前快照更新整组选中音符，统一钳制时间/音高/长度增量，保持相对间隔；真实编辑才提交一次历史，拖出释放或取消恢复模型。音长按钮、力度、量化及删除遍历选区；空选区的删除、音长和量化不写工程历史。删除按原下标筛除，切换片段/离开卷帘、加载/新建、历史恢复、改变片段长度和清空时重置选择，防止数组下标复用误操作。
- 片段记录 `start / length / offset`，裁剪和分割保留源偏移，不改写 PCM。音符和鼓点归属于节奏型；修改同一节奏型会影响所有引用。
- `MsProject` 拥有音频 PCM 指针；历史只复制 `MsSong`。导入素材追加到项目且不立即回收，使旧历史中的素材引用保持有效。新建、加载成功和退出时统一释放素材。
- 拖动时保留手势前快照，松手提交一次历史；取消恢复快照。库的 PointerCancel 会先清空 `pressed_obj`，素材拖入要区分真实移出释放和取消，避免失焦后意外添加片段。
- 保存不使用裸 C 结构体 dump。写入文件头为 `YMUSIC02`，鼓声固定为九行，每个字段显式写入；读取 `YMUSIC01` 时按旧八行布局解码，新增响指默认音量 0.8、无采样且节奏为空；加载检查引用、数量、时间、音高、力度、有限浮点和 PCM 文件剩余长度，校验完成才替换当前工程。

## 音频与线程

采样率固定为 48000，内部为立体声 float。`ms_render` 按绝对采样位置渲染同一个工程，内部分为 1024 帧块。全部九种鼓声由固定 WAV 采样加载，13 种乐器读取多音区 PCM；导入音频使用解码后的 PCM。正弦表仅供节拍器提示音，默认和弦铺底也从乐器采样渲染。轨道静音、独奏、声像、音量、片段增益与边缘淡化最终混入主输出，并钳制到 [-1, 1]。

实时播放由独立的 `music-audio` 线程补充 SDL 队列，目标为 4 × 1024 帧（约 85 毫秒）。启动时先暂停设备、预填队列，再开始消费；工作线程每约 2 毫秒检查余量，不依赖主循环 tick、界面重绘或自动保存。单音/鼓声原声试听先完整排队再启动。播放位置在互斥锁内读取已送入帧数与未消费帧数之差，循环通过连续队列和映射后的工程坐标实现，不等待队列耗尽。缓冲不包含声卡/音频服务的额外延迟，也不保证系统过载时绝不欠载。

`MsTransport` 的控制字段只在主线程读写；`MsPlayback` 持有启动时复制的工程值快照，只借用不可变音源和素材 PCM。工作线程不访问控件或原模型，游标、电平、完成状态通过 mutex 发布，取消通过原子标志通知；主线程 tick 负责启动、同步状态和收尾。编辑通过 `ms_changed` / `ms_transport_seek` 停止并等待旧线程、清队列，从可闻位置重建快照；新建、打开工程及退出必须在释放旧 PCM 前 seek/close，加载失败也保持旧工程但停止播放。不能在工作线程存活时直接释放/替换借用的 PCM。声卡或线程启动失败不假装播放，离线导出仍可工作。

导入/导出线程不访问 YMGUI。导入线程通过 `fork/exec` 参数数组启动 FFmpeg，不拼 shell 命令；返回一个新 `MsAsset`。导出线程借用当前工程和不可变 PCM；任务期间主线程禁止编辑及释放模型。原子完成标志发布结果，主线程 `SDL_WaitThread` 后接管素材或报告错误。退出先等待任务、关闭声卡，再释放模型、对象树和字库。

保持 `draw_cb` 只读：不要在绘制中读媒体、推进时间或修改模型。绘制按 band 多次调用；时间线额外收窄水平裁剪，不能让滚动到视口外的片段覆盖轨道头。

片段试听由 `ms_preview_project` 生成临时工程视图：优先当前同类轨道，保留音色/音量/声像，清空编排后仅放入所选片段；已编排片段保留 offset/length/gain/fade_in/fade_out 并将 start 平移为零，音频片段同样支持；未编排鼓/旋律使用原节奏型长度，取消轨道静音和独奏干扰。PCM 指针借用，不能释放这个副本；原工程不变。`MsTransport.track`、`pattern` 和 `clip` 随 UI 选中项同步，切换预览目标时清队列从头播放。鼓组内部静音/独奏保持有效。

当前音色编号为 0–12，全部使用采样。读取旧工程时，存储层将上一版的 13–16 / 17–20 映射到 0 / 4 / 9 / 6；超出这些已知范围仍拒绝。不得直接缩小范围后让已保存工程失效。`ms_instrument_sample` 以绝对音符位置插值读取 PCM，不依赖可变播放游标；修改音源分派须验证分块一致性。下拉框使用 `ms_checkpoint` / `ms_changed`，加载与撤销从模型恢复选中项；展开时屏蔽应用快捷键，切页/文件任务关闭浮层。

## 扩展顺序

曲库维护先读 [曲库说明](library/README.md)：`catalog.json` 使用源 MIDI 轨道编号和本应用音色编号，`sources/manifest.json` 固定来源与 SHA-256；原始 MIDI 仅保留本地、不纳入 Git，重制及完整转换回归前需按清单下载恢复，播放已附带工程不依赖它们。转换器直接编码 YMUSIC02，因此修改 `model/storage.c` 的字段或版本时须同步检查编码器、重制回归以及 C 加载器的保存重开验证。默认输出位于源码曲库，修改配器时先输出到新目录，避免覆盖已编辑工程；WAV、用户副本及 ZIP 是另行准备的 build 产物。

1. 录音和 MIDI 输入：增加独立输入适配，将事件交给应用线程；不要直接在音频回调中操作控件。
2. 音源与效果器：从统一混音路径提取可替换音源/处理器接口；播放与导出始终共享处理规则。
3. 自动化、变速、流式媒体：先扩展模型、时间映射与文件版本，再扩展界面。当前音频全量加载和固定速度模型不能直接承诺大型工程性能。
4. 修改序列化或引用结构时补往返、坏数据和历史恢复测试；修改调度时验证不同分块、循环边界、分割与离线导出一致性。

## 参考来源

[Ardour 9.8](https://github.com/Ardour/ardour/tree/9.8) 是界面功能、轨道视图、时间线、混音器组织和结构化移植的主要参考；[Hydrogen 1.2.6](https://github.com/hydrogen-music/hydrogen/tree/1.2.6) 用于研究鼓声行、Pattern 与力度编辑。本仓库 video_stidio 只用于 YMGUI 控件、中文字体和文件对话框的接入参考。十三种乐器和七种鼓声派生自 GeneralUser GS，见 [来源和许可](../../extern_lib/GeneralUser-GS/README.md)；拍手和响指使用 [CC0 实录采样](../../extern_lib/BodyPercussion/README.md)。没有复制 Ardour/Hydrogen 的 Qt/GTK 代码、图标或鼓组素材，也没有读取它们的工程格式。

`MsSounds` 持有 13 × 13 音区的浮点 PCM，乐器部分约 97.3 MB；鼓声另按实际长度持有。初始化依次加载，任一失败释放已加载资源并报告路径，不回退合成。运行不链接 FluidSynth，不解析 SF2；开发期使用 `tools/render_samples.py` 和 `tools/prepare_body_percussion.py`，保留上游来源、许可证和 SHA 清单。原始 SF2 被忽略，运行资源入库。自然音域主要为 MIDI 36–84，边缘移调不保证拟真，力度当前只改变增益。工程只存内置音色编号，不重复嵌入内置 bank；导入素材和自定义鼓采样仍嵌入工程。

采样起音只播放一次，持续类音色在 1–5 秒区间交叉循环；击弦/拨弦/定音鼓不循环，在实际移调后采样末尾短淡出归零。混音回看节奏历史按内置鼓的实际最长资源长度计算，不能再硬编码合成鼓的 1.2 秒上限，否则快速节奏中的吊镲长尾会被漏掉。

素材选择通过实际片段引用解析轨道：先保留当前已选引用，再找当前轨道的引用，最后找其他轨道的引用；找不到时仅保留同类目标并清除旧 clip。音色属于轨道，不属于共享节奏型。素材拖动保持 Pointer 捕获，移动超过 6 像素后在 top layer 显示卡片，在时间线绘制落点；预览不改写模型。释放前重新校验类型/长度/容量，取消检查 pressed_obj 已被清除，隐藏卡片并失效旧区域。淡化输入单位为秒，0–10，提交前验证有限值；整曲、片段试听和 WAV 导出共用同一乘法包络，原声试听不应用编排片段效果。

工作区为 1680×1050，`MS_GRID_WIDTH`、`MS_DRUM_ROW` 和 `MS_KEY_ROW` 用于绘制与命中共同计算，修改时同时更新输入注入测试。13 种音色使用一个现有 Dropdown，不增加核心控件上限或另存音源分类。扩展样本时同步资源清单、加载表、名称、自然衰减/循环规则与测试。

钢琴步长选择只改变新音符默认长度和交互步长，不改已有音符、不产生工程撤销记录。新音符起点按当前步长向下吸附；移动与右端缩放按相对手势增量吸附，保留曲库的非网格起点，最短长度为 1 tick。音长加减从所选音符的实际长度开始；量化显式吸附起点并限制在乐句边界内，不裁短原音符。绘制与命中共用最小 3 像素宽度，缩放手柄按实际显示宽度缩小到 1–6 像素，确保极短音符仍可移动及拉长。自由模式保留十六分节拍参考线，其他模式绘制对应细分线；音色与步长两类下拉弹层均阻止应用快捷键，切页或文件任务关闭弹层。
